## 0. 合規基線(先讀這段,全部流程都受它約束)

本計劃承接手冊第 10.3、10.4 節與第十一章「禁用話術與合規替代」,以下為不可逾越的紅線,已內建到自動化流程的審核閘門(見第 3.4 節):

1. **不做人設,直接輸出內容**:不建立虛擬陪伴角色;私訊與留言不扮演任何角色、不暗示真人一對一關係。所有帳號簡介標明「內容由 AI 協助製作,團隊運營」。禁用「我是真人單身女性,只對你這樣」等身分誤導話術。
2. **不誘導依賴與打賞**:禁用「只有我懂你」「不續費我就消失」「刷禮物證明你在乎我」;替代話術一律導向「你值得多方支持,也可以找現實中可信任的人聊聊」「是否續費完全由你決定」。
3. **危機處理高於一切商業目標**:用戶出現自傷訊號時,依手冊 10.3 模板回應,轉介專業資源——大陸:110/120、心理援助熱線 12356;台灣:110/119、安心專線 **1925**、生命線 **1995**、張老師 **1980**。危機中或危機後**不推薦會員、打賞、課程或任何付費**。危機用戶不留給 AI 單獨處理,需人工接手。
4. **金流只走平台官方結算**:不使用「我生病/欠租/手機壞了,幫幫我」等虛構困境索財話術。
5. **AI 內容依法標註**(詳見 2.3 節):大陸《人工智能生成合成內容標識辦法》2025-09-01 起強制顯式+隱式標識;YouTube/TikTok/Meta 上傳合成內容需勾選 AI 揭露。**標註不是選項,是發佈流程的必要欄位。**
6. **自動化只用平台官方 API 或官方創作者工具**,不用模擬點擊/群控等違規手段——被封號的「套利」不是套利。

## 1. 商業模式:內容套利飛輪

「套利」的本質:**用 AI 把單支內容的邊際成本壓到接近零,同一素材產一次、鋪滿兩岸 8 個平台,吃各平台對短影音的流量紅利,再把免費流量轉進高毛利的會員訂閱。**

依手冊,內容同時承擔四任務:**獲客 → 建立信任 → 證明有效 → 推動續費**。

```
Claude 產選題/腳本(邊際成本 ≈ $0.02/支)
        │
        ▼
TTS + FFmpeg 自動合成短影音(≈ $0/支,本地運算)
        │
        ▼
一支內容 → 簡/繁兩版 → 8 平台分發(官方 API / 半自動)
        │
        ▼
免費 30–60 秒短內容獲客(下班關機、男人沒說出口的話…)
        │
        ▼
私域/訂閱承接:大陸→企業微信+平台課程;台灣→LINE OA 訂閱制
        │
        ▼
會員內容變現:3–10 分鐘完整音頻、對話腳本+練習表、七晚聲音計畫、直播討論
```

### 目標用戶(引手冊第二章)

- 35–55 歲,企業管理者、專業人士、個體經營者、創業者,承擔家庭主要經濟責任
- 白天解決大量問題,很少有機會表達疲憊;不喜歡煽情,不願接受「心理諮商」標籤
- **晚上 9 點至凌晨是主要內容消費時間**
- 願為節省時間、改善睡前狀態、降低家庭衝突付費;偏好私密、克制、不尷尬的服務
- 對「賣慘」「曖昧索取」「強行推銷」有強戒備心 → 文案調性必須克制

## 3. 全自動化流水線(Claude 為核心)

架構:**Python + SQLite 內容庫 + cron 排程**,單機(或一台 VPS)即可跑。五個階段:

```
[3.1 選題] → [3.2 產腳本+文案] → [3.3 產短影音] → [3.4 合規審核閘門] → [3.5 排程發佈]
   Claude        Claude              TTS+FFmpeg        Claude(rubric)      官方 API / 待發匣
```

### 3.1 選題引擎(每週日跑一次,產一週選題庫)

- 輸入:六大內容支柱(手冊第五章)+ 當週熱點關鍵字(可選,人工丟進一個 `trends.txt`)
- Claude prompt 要點:每支柱產 5–8 個題目,格式仿手冊典型題目——**一句有畫面感的問句或觀察**,如《為什麼很多男人回家前會在車裡坐十分鐘》《過了三十五歲,別人只問你有沒有辦法》
- 輸出:JSON 選題庫(支柱、標題、目標情緒、免費版形式、對應會員內容鉤子),寫入 SQLite

### 3.2 腳本 + 文案生成(每日 cron)

- 每支影片一次 Claude 呼叫,同時產出:
  1. **30–60 秒旁白腳本**,三段式:**Hook(前 3 秒,說出他沒說出口的話)→ 共鳴(描述場景,不下判斷)→ 收束(一個可立刻做的小動作 + 輕 CTA)**
  2. **簡體版**(大陸軌)與**繁體版**(台灣軌)文案——不是機器轉換,是讓 Claude 針對兩地語感各寫一版(大陸:「下班」「較勁」;台灣:「下班」「硬撐」,用詞在地化)
  3. 各平台 hashtag 組合(見第 5 節規則)
  4. 對應會員內容的一句話鉤子(「完整版 8 分鐘音頻在會員區」)
- 調性約束寫死在 system prompt:**克制、不煽情、不賣慘、不曖昧**(手冊用戶特徵第 19、23 條)

### 3.3 短影音自動合成

風格:**文字卡 + 氛圍實拍素材 + 低沉男聲旁白 + 大字幕**——刻意「低製作感、高可信感」,符合目標用戶對煽情內容的戒備。

| 環節 | 工具 | 成本 |
|---|---|---|
| 配音 | Edge-TTS(免費,`zh-CN-YunxiNeural` 簡體 / `zh-TW-YunJheNeural` 繁體)起步;品質升級再換 Minimax 或 ElevenLabs | $0 起 |
| 背景素材 | Pexels/Pixabay 免版稅夜景、車內、辦公室空鏡,建 50 支素材池輪用 | $0 |
| 字幕 | 腳本自帶時間軸(Claude 產出時逐句標秒數),FFmpeg `subtitles` filter 燒錄 | $0 |
| 合成 | FFmpeg:素材裁 9:16 → 疊字幕 → 混音(旁白 + 低音量氛圍音樂)→ 輸出 1080×1920 MP4 | $0 |
| 封面 | FFmpeg 抽幀 + 標題文字卡 | $0 |

同一腳本產兩版:簡體配音+簡體字幕(大陸軌)、繁體配音+繁體字幕(台灣軌)。

### 3.4 合規審核閘門(不可跳過)

1. **Claude 自動審稿**:以手冊第十一章「禁用話術與合規替代」+ 10.4「絕不能做」建成 rubric,逐條檢查腳本與文案。輸出 `PASS` 或 `FAIL + 違規條目 + 建議改寫`;`FAIL` 自動退回 3.2 重寫,最多兩輪,仍不過就進人工匣。
2. **AI 標註檢查**:確認發佈參數含 AI 揭露標記與元數據隱式標識。
3. **人工抽查**:全自動發佈,但每日發佈清單推送到你的 LINE/微信,**每天花 10 分鐘抽看 2–3 支**。這一步保留人在迴路,是合規基線的一部分,不因「全自動化」省略。

### 3.5 排程發佈

| 軌 | 方式 |
|---|---|
| YouTube Shorts | YouTube Data API `videos.insert`,cron 準點觸發 |
| FB / IG Reels | Meta Graph API container 流程(建 container → 輪詢 FINISHED → publish) |
| TikTok | Content Posting API Direct Post(API 本身無排程,由 cron 控制觸發時間) |
| 抖音 / 視頻號 / 快手 / 小紅書 | **半自動**:pipeline 產出「待發匣」(影片 + 文案 + 話題標籤打包,檔名含建議發佈時間),每日推提醒;上傳時用各平台創作者後台的**原生定時發佈**功能,一次排一天份,實際操作約 15 分鐘/日。不使用模擬操作腳本或群控工具——封號風險遠大於省下的時間 |

> 大陸四平台的 15 分鐘/日人工上傳,是目前唯一合規解;計劃書如實標明,不假裝有全自動方案。

## 5. 文案模板與 Hashtag 策略

### 5.1 文案結構(每支柱 2 組模板,Claude 依此變體)

**支柱一:下班關機**
> Hook:「你有沒有算過,你在車裡坐了幾分鐘才上樓?」
> 正文:「不是不想回家。是那十分鐘,是你一天裡唯一不用扮演誰的時間。」
> CTA:「今晚,把那十分鐘留給自己。完整的 8 分鐘下班音頻,在會員區等你。」

**支柱二:男人沒說出口的話**
> Hook:「過了三十五歲,別人只問你有沒有辦法,沒人問你累不累。」
> 正文:「你不是沒情緒,你只是把它排在所有人後面。」
> CTA:「這封來信的完整回應,今晚 10 點會員區上線。」

**支柱三:家庭溝通**
> Hook:「『我需要安靜』和『你們都別煩我』,差的不是脾氣,是說法。」
> 正文:一句話示範(手冊格式):「我現在需要二十分鐘,等一下我來找你。」
> CTA:「完整對話腳本和練習表,在會員區。」

**支柱四:人生中場**
> Hook:「如果不再用職位介紹自己,你還剩下什麼?」
> 正文:「這不是危機,是中場。中場的意思是——還有下半場。」
> CTA:「系列課程第一講,免費試聽。」

**支柱五:父親與兒子**
> Hook:「父親最難道歉的,往往不是做錯了什麼。」
> 正文:故事片段,不下結論。
> CTA:「這段關係的復盤和行動任務,在會員區。」

**支柱六:身體先下班**
> Hook:「今晚,先把肩膀放下來。」
> 正文:30 秒跟做放鬆提示。
> CTA:「七晚聲音計畫,今晚開始。」

**禁區**(審核閘門自動攔截):賣慘、曖昧(「只對你」「證明你在乎我」)、威脅式挽留(「不續費我就消失」)、冒充真人單身女性、危機內容後接任何付費 CTA。

### 5.2 Hashtag 三層結構(每支 5–8 個)

| 層 | 作用 | 大陸(抖音/視頻號話題) | 台灣(TikTok/IG/YT) |
|---|---|---|---|
| 大流量層(1–2 個) | 進大池子 | #下班 #中年 #情绪价值 | #下班 #中年 #心理健康 |
| 垂直層(2–3 個) | 精準匹配畫像 | #中年男人 #职场压力 #35岁 #家庭责任 | #中年危機 #職場壓力 #男人的壓力 #爸爸 |
| IP 專屬層(1–2 個) | 累積品牌搜索 | #晚风值班室 #今晚先把肩膀放下来 | #晚風值班室 #今晚先把肩膀放下來 |

- 小紅書旁路版改掛:#老公 #中年夫妻 #睡前音频(對妻子受眾)
- YouTube Shorts:hashtag 放描述前三個(#Shorts 必帶);FB 少掛(2–3 個即可,FB hashtag 權重低,重點在粉專/社團分發

### 5.3 簡繁在地化規則(寫進 Claude system prompt)

- 台灣版:「影片、會員、訂閱、硬撐、老婆」;大陸版:「视频、会员、续费、较劲、爱人」
- 危機資源隨版本切換(1925/1995 vs 12356),絕不混用

單支內容邊際成本 < $0.1,這就是套利空間:同支內容 8 平台分發,任何一個平台跑出量,獲客成本都趨近零。

### 90 天冷啟動里程碑

| 階段 | 目標 | 判斷指標 |
|---|---|---|
| D1–30 打地基 | 8 平台開號、pipeline 上線、日更穩定 | 每日 4 支準時發佈率 >95%;完播率基線建立(Shorts/抖音 3 秒留存 >60%) |
| D31–60 找爆款 | 用數據砍支柱 | 每支柱 ≥15 支樣本;砍掉完播率後 1/3 的題型;出現 1–2 支 10 萬+ 播放 |
| D61–90 開變現 | 私域與訂閱承接 | 私域(LINE OA/企微)導流轉化 >2%;會員轉化 >5% 私域用戶;續費意願調查啟動 |

### 數據回收(pipeline 第六階段,D31 起)

- YouTube Analytics API / Meta Insights / TikTok API 每日拉取播放、完播、轉化;大陸平台手動週報(創作者後台匯出)
- Claude 每週日讀數據 → 產「支柱表現週報 + 下週選題權重調整」,形成閉環
