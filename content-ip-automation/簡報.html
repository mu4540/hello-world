五條紅線:寫進 Agent 的系統規則,也寫進你腦子

  1. 不做人設、不搞角色互動。頻道直接輸出內容;私訊與留言不扮演任何角色、不暗示真人一對一關係。簡介標明「內容由 AI 協助製作,團隊運營」。
  2. AI 內容必須標註。大陸 2025 年 9 月起法規強制(抖音/微信有 AI 標識開關);YouTube/TikTok/Meta 上傳時勾 AI 揭露。每支必勾,忘了=違規。
  3. 不誘導依賴、不誘導打賞。「只有我懂你」「不續費我就消失」「刷禮物證明你在乎」全部禁用。
  4. 危機處理高於一切。用戶透露自傷訊號 → 照危機頁流程,之後永久不對他推銷。危機不留給 AI 單獨處理。
  5. 金流走平台官方結算;自動化只用官方 API 與官方後台。不碰群控、模擬點擊、買量。
為什麼要守?這個受眾對「賣慘、曖昧、強推銷」戒備極強,違規話術會直接趕跑他們——克制本身就是這個 IP 的賣點。加上封號與法律風險,沒有任何理由越線。

常見問題

發了兩週都沒流量?

正常,演算法要 20–30 支才摸清受眾。只查兩件事:前 3 秒留存 >60%?(否→Hook 不夠痛)有沒有天天準時發?不要頻繁刪片重發。

被限流/警告?

查三件事:AI 標註勾了沒、當天是否發超過 2 支、文案有沒有誘導詞。修正後停一天再恢復。絕不買假流量。

TikTok API 被拒?

補齊用途說明(own-account content publishing)+ 隱私政策連結重送。被拒不影響手動發佈,照常日更。
